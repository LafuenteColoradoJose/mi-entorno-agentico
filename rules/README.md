# 📜 Rules

Las reglas de esta carpeta son **genéricas y obligatorias**: se acatan en el 100% de
las tareas, sin importar la tecnología del proyecto.

- Las **reglas específicas de un proyecto** (convenciones de dominio, "usar siempre la
  API X", etc.) van en el `AGENTS.md` de ese proyecto, no aquí.

→ Ver la explicación completa en el [**README principal · genérico vs. específico**](../README.md#generico-vs-especifico).
